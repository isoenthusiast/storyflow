# Changelog

## 0.1.0 — 2026-10-21

- Standalone editorial desk with seven stages, drafts, review checks, search,
  archive/restore, saved versions, and an activity timeline.
- Conversation fields and a version-checked API for connected agents.
- Generic writing profile, browser-local dates, configurable database/profile/host.
- Fictional example, private-network instructions, and optional integration contracts.
- SQLite backup and restore, automated tests, and cross-platform CI.

Known limits: no built-in agent, publishing or narration integration; no user
accounts; no JSON import UI; no automated revision rollback. The first release
is a foundation for adaptation, not a public hosted service.
