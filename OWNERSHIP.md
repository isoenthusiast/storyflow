# StoryFlow — workspace ownership

The public-facing copy of this workspace's ownership record. The internal estate record
stays with the workspace on the owner's machine and is not published here.

Owner: Edward — ratified 25 November 2026.

Reusable self-hosted editorial desk: ideas, research, drafts, review decisions and next
actions persist across conversations. Separate from the production WeeWrite workspace and
from the earlier Author's Desk review package.

- **Project documentation:** [README.md](README.md), [AGENTS.md](AGENTS.md)
- **Repository:** `https://github.com/isoenthusiast/storyflow.git` — branch `main`
- **Status (documentary, 2026-11-07):** CHANGELOG records v0.1.0 on 21 October — Python standard
  library, SQLite, plain web UI, seven workflow stages, version-checked API and backup/restore.
  README calls it an early single-workspace foundation. No current release or deployment query
  was performed.
- **Boundaries:** generic author/site/provider/timezone configuration. A connected agent must
  read current versions, preserve source/draft fields, reconcile conflicts and read back
  updates. Ready, Scheduled and Published labels do not execute or prove publication. There is
  no built-in agent, publishing or narration integration, and no accounts.
- **Next gate:** integrations require separate implementation and publishing authorization. JSON
  import UI, automated revision rollback and accounts are absent in v0.1; do not imply hosted
  multi-user readiness.
