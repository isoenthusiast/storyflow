# A five-minute walkthrough

Run the two demo commands in README.md. The fictional example is clearly
labelled and uses a separate database; it contains no real personal experience.

1. Open the example in Review. Read the Conversation tab: summary, decisions,
   unanswered questions, next action, and the three-event timeline.
2. Open Draft and change the opening. Save, reload, and check it persisted.
3. Open Review and View saved versions to see the earlier text. Download a
   handoff to see what another assistant could use as context.
4. Archive the idea, find it under Archived ideas, and restore it.
5. Create your own title. Choose a reader and next action before writing a draft.

Marking Ready does not publish. Published requires a publication link, but the
app cannot verify that it really exists. Do not describe the demo as a live
publication or an automatically synchronized chat.

For a short screen recording, show the question, the draft, and the timeline.
Explain that a connected agent can maintain these same fields during a real
conversation; the demo itself is seeded example data.
